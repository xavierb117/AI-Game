## AI-Game
A game where you must reach the sum before time runs out. Test out your math solving skills with this game.
## Rules
- Control the green triangle with the arrow keys.
- Touch one of the 16 squares to add to your current sum at the right side of the screen.
- A timer counts down from 3 minutes. If you don't reach the sum by the end of the the countdown, you lose.
- You can only visit a square once. You can't revisit it again. 
- If you visit all squares without reaching the sum, you lose.
- If your current sum reaches the target sum, you win!
